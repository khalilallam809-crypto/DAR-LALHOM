# Polyglot App - Local Setup Guide

This project is a modern, high-performance multilingual React application.

## Prerequisites

Before building and running the app locally, ensure you have **Node.js** installed:

- **Node.js**: Download and install from [nodejs.org](https://nodejs.org/) (Version 18 or 20 recommended).

## Getting Started

1. **Clone or Open the project** in your preferred editor (like VS Code).
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Run the Development Server**:
   ```bash
   npm run dev
   ```
4. **View the App**: Open [http://localhost:3000](http://localhost:3000) (or the port shown in the terminal) in your browser.

## Built With

- **React** with Vite
- **Tailwind CSS** for styling
- **Motion** for animations
- **Lucide React** for icons
- **Multilingual Support**: English, French, and Arabic (RTL)
